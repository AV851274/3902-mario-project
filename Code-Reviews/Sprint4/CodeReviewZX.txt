Sprint 4

Readability: 8.5/10

The LevelLoader component experienced a significant code refactoring compared to
the previous sprint, though its behavior remained largely unchanged. 
This update split the long LevelLoader.cs file into several smaller files and delegated the parsing 
task to different concrete handlers classes. This has improved the code’s readability.
I think an area for improvement is the for loop in the LoadLevel static method,
which isn’t very clear; adding a few comments could further enhance its readability.

Maintainability/Quality: 9/10

By creating a handler interface and multiple concrete classes, the responsibilities 
of the classes have become clearer, and cohesion has increased. 
I believe one area for improvement would be to replace the dependencies of some 
handlers on the concrete SpriteFactory with the ISpriteFactory interface, 
in order to further reduce coupling.
